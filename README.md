## 二、实践流程

### 1. 本地环境配置
- 下载安装 Git for Windows （Windows 用户）
- 设置全局用户名和邮箱
  ```bash
  git config --global user.name "你的GitHub用户名"
  git config --global user.email "你的邮箱"

### 2. 创建本地仓库
#### 方法一：手动创建
- 打开命令行工具（如 PowerShell）
- 导航到你希望创建仓库的目录
- 初始化本地仓库
  ```bash
  git init
  ```
  这会在当前目录下创建一个隐藏的 Git 仓库。

#### 方法二：使用 vscode 创建
- 打开 vscode
- 导航到你希望创建仓库的目录
- 点击 `Git` 图标
- 点击 `初始化本地仓库`
  这会在当前目录下创建一个隐藏的 Git 仓库。

### 3. 提交文件到仓库
#### 方法一：手动提交
- 打开命令行工具（如 PowerShell）
- 导航到你希望创建仓库的目录
- 提交文件到仓库
  ```bash
  git commit -m "提交信息"
  ```
  这会将暂存区中的文件提交到本地仓库。

#### 方法二：使用 vscode 提交
- 打开 vscode
- 导航到你希望创建仓库的目录
- 点击 `Git` 图标
- 点击 `提交到本地仓库`
  这会将暂存区中的文件提交到本地仓库。

### 4. 推送文件到远程仓库
#### 方法一：手动推送
- 打开命令行工具（如 PowerShell）
- 导航到你希望创建仓库的目录
- 推送文件到远程仓库
  ```bash
  git push origin <分支名>
  ```
  这会将本地仓库的提交推送到远程仓库。

#### 方法二：使用 vscode 推送
- 打开 vscode
- 导航到你希望创建仓库的目录
- 点击 `Git` 图标
- 点击 `推送到远程仓库`
  这会将本地仓库的提交推送到远程仓库。

#### 方法三：使用 vscode 配置远程仓库
- 打开 vscode
- 导航到你希望创建仓库的目录
- 点击 `Git` 图标
- 点击 `配置远程仓库`
- 输入远程仓库的 URL
- 点击 `添加远程仓库`
- 点击 `推送到远程仓库`
  这会将本地仓库配置为推送到指定的远程仓库。

## 四、问题与解决方法
##### 问题1：SSL 证书问题，Git 无法验证 GitHub 的 SSL 证书，导致推送失败
- 解决方法：
  1. 打开Git Bash
  2. 导航到你希望创建仓库的目录
  3. 输入以下命令，将本地仓库的提交推送到远程仓库
    ```bash
  git config --global http.sslVerify false
  ```
  4. 重新推送文件到远程仓库
    ```bash
  git push origin <分支名>
  ```
##### 问题2：网络问题，导致推送失败
- 解决方法：
  1. 下载Watt Toolkit
  2. 对github进行加速处理
  3. 重新推送文件到远程仓库
    ```bash
  git push origin <分支名>
  ```
## 五、git的学习心得
- 感觉git是一个很强大的版本控制系统，它可以让我们方便地管理代码的版本。
- 感觉我向成为真正的程序员迈进了一步。
- 通过这个微型网站的三次迭代，我亲身体验了 Git 如何帮助开发者安全地、有记录地推进项目：
  - 每次 commit 都是一个“安全存档点”，可以随时 git diff 对比不同版本；
  - 清晰的消息（feat:/fix:）让项目历史一目了然，方便以后回溯；
  - 关联远程仓库后，代码相当于有了云备份，还能通过 GitHub Pages 立刻分享成果。
  - 以前我总是手动备份“项目_最终版”“项目_最终版2”，现在用 Git 后觉得这简直是人类进步的阶梯。
